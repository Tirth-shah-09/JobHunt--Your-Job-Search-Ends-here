#  JobHunt — Full-Stack Job Recruitment Platform

**JobHunt** is a modern, full-stack job recruitment web application designed to connect job-seeking students with top recruiters and companies. Built from scratch with a robust REST API backend and a responsive React + Tailwind CSS frontend.

---

##  Key Features

### For Students
- **Browse & Search Jobs:** Explore available job listings with advanced details (location, job type, experience level, requirements).
- **One-Click Applications:** Easily apply to jobs with an integrated profile and resume.
- **Application Tracking:** Real-time status tracking (`applied`, `pending`, `rejected`) for all submitted applications.
- **Profile & Resume Management:** Update personal bio, skills, contact info, and resumes.

### For Recruiters
- **Company Management:** Register and update company profiles (name, website, location, description).
- **Job Posting & Management:** Post new job vacancies, edit existing listings, and manage openings.
- **Applicant Dashboard:** View all applicants per job, inspect student credentials/resumes, and update application statuses.

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, React Router, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** Cookie-based session authentication with secure HTTP-only cookies
